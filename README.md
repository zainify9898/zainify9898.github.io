# Muhammad Zain Ul Islam — Portfolio

Animated dark-mode portfolio website for Muhammad Zain Ul Islam, AI/ML Intern @ Zynvex Solutions and BS Artificial Intelligence student at Riphah International University.

**Live site:** https://zainify9898.github.io

## Design

Void-canvas system: true black (`#000000`) with near-black `#111111` panels and a single rationed electric-blue accent (`#0099FF`). Rounded geometric display type with tight tracking, Inter body text, and a monospace console register. The hero is a working software canvas — a layers panel, project stage, and a live agent chat that answers questions about his skills, projects, and internships. Motion throughout: film grain, blinking console cursor, shimmer sweeps, scroll-triggered staggered reveals, and animated counters.
